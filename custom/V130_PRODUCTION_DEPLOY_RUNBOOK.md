# v1.30 生产部署 Runbook

本文件为不执行方案；所有主机、账户和路径均使用占位符。

## 共同准备

1. 确认托管目标、维护窗口、回滚负责人和上一版本位置。
2. 上传 `release/v1.30-rc.1/` 到独立临时目录，核对 151 个文件与关键 SHA-256。
3. 替换 nginx 模板中的证书和 Web Root 占位符；保存现行配置备份。
4. 在任何 reload 前执行 `nginx -t`；失败即停止。

## 方案 A：软链接原子切换

- 版本目录：`<RELEASES_ROOT>/v1.30-rc.1/`。
- 当前入口：`<CURRENT_LINK>` 指向现行版本。
- 记录旧目标，创建指向新版本的临时链接后原子替换 `current`。
- `nginx -t` 通过后 reload，立即执行 smoke test。
- 回滚：原子切回记录的旧目标，复跑 `nginx -t`、reload 和关键检查。

## 方案 B：目录备份 / root 切换

- 将现行 `<WEB_ROOT>` 快照或重命名为带时间戳的备份，不覆盖。
- 上传新目录并完整校验；修改 nginx root 指向新目录。
- `nginx -t` 通过后 reload，执行 smoke test。
- 回滚：root 指回备份目录，再次测试并 reload。

## 失败触发器

首页/五栏目不可达、资源缺失、真实 404 错误、证书错误、跳转循环、robots 阻止索引、canonical 域错误或关键移动布局破坏，任一出现即停止并回滚。禁止在生产目录临时编辑源码来掩盖问题。
