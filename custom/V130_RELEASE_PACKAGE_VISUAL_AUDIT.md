# v1.30-rc.1 发布包视觉抽检

测试根：`http://127.0.0.1:8090/`，服务根目录为 `release/v1.30-rc.1/`，不是源码目录。

## 页面与视口

- 六个入口：首页、探索柚木、柚木美学、柚木生活、特色品牌、生态合作。
- 四类详情：`what-is-teak`、茶室空间参考、柚木餐桌、壹信柚木。

## 结论

- 桌面视觉：PASS；移动视觉：PASS。
- 20/20 组均为单一 H1、单一 main、单一 footer。
- 文档 `scrollWidth` 与 `clientWidth` 相等：20/20，无页面级横向溢出。
- 已加载图片 `naturalWidth=0`：0。
- 首页、五栏目和四类详情首屏与源码验收一致，打包未造成字体、CSS、JS、图片、导航或模板缺失。
- 首页法律页脚在 1366 与 390 视口显示正常；公司名称可自然换行，ICP备案链接、二维码、导航均无挤压或裁切。

本结论只证明隔离发布包的本地浏览器表现；二维码目标已由用户真实微信扫码确认，生产 TLS、域名跳转与服务器行为仍按各自生产清单验证。
